# 操作ガイド

[READMEへ戻る](../README.md)

## 録音モード

**会議音声**では，選択アプリまたはMac全体の再生音声とマイクを録音します．自分の声を含めない場合は，マイク行の「オン／オフ」をオフにしてください．**マイクのみ**では，選択した入力マイクだけを録音します．システム音声のTapは作成せず，その許可にも依存しません．

入力はMac内蔵マイク，AirPods，USBマイクなどから選べます．録音中の入力デバイス変更はできません．切断時に別のマイクへ自動で切り替えることもありません．マイク音声をイヤホンへ返すモニタリングは行いません．

## パネルと設定

- 入力欄から，再生音声の対象とマイクを選びます．メーターにポインターを置くと入力形式を確認できます．
- 「録音名」は開始前に編集できます．保存後は鉛筆ボタンから名前・保存場所を変更できます．
- 歯車から，通知，会議名の取得，保存先，停止時の名前確認を設定します．
- 「…」から，一覧の更新，未完了録音の回復，終了を操作します．
- エラーが表示された場合は「i」から詳細を確認できます．録音・保存中は通常の終了を抑止します．

## 会議候補の通知

初期状態では通知がオンです．Zoom／Teams／対応ブラウザーのマイク入力利用を約3秒ごとに確認し，2回連続で検知するとポップアップを表示します．検知処理自体は音声を録音しません．

「録音開始」を押すと，検知したアプリを対象に会議モードで開始します．マイクの種類とオン・オフはOtologの現在の設定を使います．「今はしない」や閉じる操作では録音しません．通知は30秒で閉じ，同じ入力利用が続く間は繰り返しません．入力利用が30秒以上途切れると，次の候補として扱います．

対応ブラウザーはChrome，Safari，Edge，Firefox，Brave，Arcです．任意の会議名取得とアクセシビリティ許可があれば，対象アプリの最大5ウインドウのタイトルからサービス・会議名の識別を補います．本文，URL，スクリーンショットは取得しません．タイトルを取得できない場合は，「Chromeのマイク利用」などの一般的な候補として通知します．

会議参加を確定する判定ではありません．会議以外のマイク利用でも通知し，ミュート参加や関連プロセスの識別ができない環境では見逃す場合があります．その場合はメニューバーから手動で開始してください．「設定」→「通知をプレビュー」で，録音せず見た目を確認できます．

## 会議名とJST日時

取得した会議名はパネルの既定名に入り，開始時に録音へ引き継ぎます．一般的なアプリ名やホーム画面名を議題名として使わないようにしていますが，実際の会議名を公開しないアプリでは取得できません．Google Meetではコードしか取得できない場合があります．

名前が空の場合は，OSのタイムゾーンによらず`Asia/Tokyo`で録音開始日時を付けます．会議名と開始日時は回復用JSONに残るため，後日の回復でも使えます．同名には` (2)`などを追加します．ファイル名に使えない文字を置き換え，長い名前はUTF-8で200バイト以内へ制限します．

「停止時に保存名を確認」をオンにすると，完成ファイルを検証・保存した後に名前変更ダイアログを開きます．キャンセルや変更失敗でも，元の完成ファイルを残します．既存ファイルを選んだ場合は上書きを拒否します．

## 音声データが届かないとき

「相手側の入力を待っています」は，選択対象からPCMデータを受信していない状態です．無音のPCMを受け取っている状態とは異なります．データ未受信だけでは，許可不足，再生停止，取得経路の問題を区別できません．

1. 選択した対象で実際に音声を再生してください．
2. 特定アプリで届かない場合は，対象が起動していることを確認し，一覧を更新します．関連プロセスを識別できない場合はMac全体で試してください．
3. システム設定の録音許可を確認し，必要ならOtologを再起動します．
4. メーターと，保存後の再生を確認してください．

一度も相手側データが届かずに停止した場合は，保存結果にもマイクのみ／無音の可能性を表示します．会議名や通知が表示されても，音声の取得成功を意味するものではありません．

## 容量不足・異常終了からの回復

1. 保存先の空きを確保します．完成AACの作成にも空きが必要です．
2. 保存先にある`.recording`フォルダーをそのまま保持してください．
3. Otologを起動し，「…」→「未完了の録音を回復」から再試行します．

別ディスクへ移す場合は，`.recording`フォルダー全体を移し，Otologの保存先をその親フォルダーに変更します．読めないセグメントがある場合は，回復できた音声を保存し，警告と元データを保持します．詳細は回復フォルダーの`Recovery-warning.txt`です．

## Xcodeの初期設定

ビルド時にライセンスや初期設定のエラーが出た場合は，Xcodeを起動して案内に従ってください．ターミナルで行う場合は，内容を確認してから次を実行します．

```sh
sudo xcodebuild -license
sudo xcodebuild -runFirstLaunch
```

CLIから参照しているXcodeは`xcode-select -p`と`xcodebuild -version`で確認できます．
